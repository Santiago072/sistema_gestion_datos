# Módulos del Sistema

Este documento lista y describe los módulos principales que componen el sistema de gestión de datos.

## 1. Aprendices
Módulo central encargado de la gestión de los aprendices. Permite realizar operaciones CRUD (registro, consulta, actualización y eliminación) así como asociar a los aprendices con sus respectivos programas de formación.

## 2. Programas
Se encarga de la gestión del catálogo de programas de formación. Aquí se definen los diferentes programas y se asocian las fichas correspondientes.

## 3. Fases
Administra las fases del proceso formativo (ej. Análisis, Planeación, Ejecución, Evaluación). Estas fases son fundamentales para categorizar los juicios y medir el progreso.

## 4. Juicios
Gestiona los resultados y juicios evaluativos que reciben los aprendices en cada fase de su formación. Este módulo es clave para el seguimiento académico.

## 5. Dashboard
Módulo analítico que toma los datos de todos los módulos anteriores para generar indicadores clave de rendimiento (KPIs), estadísticas y gráficas visuales que facilitan la toma de decisiones.
